# NLP-LAB

SMARTMENTOR

An Intelligent Faculty Mentorship and Recommendation System

1. Project Overview

SmartMentor is an intelligent faculty mentorship system developed using Python and Natural Language Processing (NLP). The application helps students identify and connect with suitable faculty mentors based on their academic interests, requirements, and areas of specialization.

The system aims to simplify the mentor discovery process and improve student-faculty interaction through an organized and user-friendly platform.

2. Problem Statement

Students often face difficulties in identifying faculty members who match their academic interests and requirements. Traditional mentor selection methods may involve manual searching and consume considerable time.

SmartMentor addresses this problem by providing a centralized platform to explore faculty information and discover suitable mentors.

3. Objectives

- To develop an intelligent faculty mentorship platform.
- To simplify faculty searching and mentor discovery.
- To organize faculty information systematically.
- To improve student-faculty interaction.
- To apply Natural Language Processing concepts in an academic application.

5. Dataset

The project uses a CSV dataset named "faculty_dataset.csv".

The dataset stores faculty-related information required by the application.

The dataset is used to retrieve and process faculty information during application execution.

6. System Modules

1. Home Page: Provides the main interface of SmartMentor.
2. Faculty Search: Helps users search for faculty information.
3. Faculty Details: Displays available faculty information.
4. Mentor Discovery: Helps students explore potential mentors.
5. Dataset Management: Uses the faculty dataset to retrieve relevant information.

7. Methodology

The application follows these general steps:

1. Collect faculty-related information.
2. Store the information in a structured CSV dataset.
3. Accept user search requirements.
4. Process the available information.
5. Identify relevant faculty information based on the implemented matching method.
6. Display the results through the web interface.

10. Installation and Execution

Step 1: Install Python on the system.

Step 2: Open the SmartMentor project folder.

Step 3: Open the terminal in the project directory.

Step 4: Install the required dependencies.

pip install -r requirements.txt

Step 5: Execute the application.

python app.py

Step 6: Open the local URL displayed in the terminal in a web browser.
